Study Room

Live demo · Java 21 · Spring Boot · WebSocket · Redis · PostgreSQL · React · Docker

A web app for studying in the same room as your friends with one shared Pomodoro timer. No accounts: you type a name, create a room and share the code. When someone starts the timer, it starts for everybody at once.

The server owns the timer: state lives in Redis, every browser computes the remaining time from the server's clock, and WebSocket keeps everyone in sync. Only the room's creator can change the lengths (authorization with anonymous JWTs). Since there are no accounts, your streak and daily focus time stay on your device.

Packaged with Docker and live on Render + Neon + Redis. I wrote 44 automated tests for it.

Gams N' Roses

Hackathon winner (1st place) · team project · GAMSPy · Python · JavaScript

A game my teammates and I built at the Gamification of Optimization Hackathon, organised by AGU Computer Society and GAMS. We didn't just turn the problem into a game, we wrapped it in a story: you're helping a band called Gams N' Roses that wants to play a concert in the city. To give the band a real feel, we even made them a song with the help of AI, given the hackathon's tight time limit, and used it as the game's soundtrack.

The game tackles a real problem cities face: noise pollution. On a randomly generated city map you pick where the stage goes, then place speakers and sound barriers on a limited budget; the goal is to give the audience the best sound without disturbing sensitive buildings like hospitals and libraries.

At the end, Dr. GAMS takes the stage: GAMSPy works out the mathematically best layout for the same stage, and Dr. GAMS scores how close your setup came to that optimum. We finished the competition in first place.
